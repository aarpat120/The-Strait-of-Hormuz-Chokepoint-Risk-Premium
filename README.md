# The-Strait-of-Hormuz-Chokepoint-Risk-Premium
This spreadsheet shows that wars and shipping blockades raise oil prices. Between February and May 2026, Brent crude increased from about $72 to over $101 per barrel. Smaller conflicts caused temporary price spikes, but prices calmed after a 60-day ceasefire, showing how quickly markets react to conflict.
